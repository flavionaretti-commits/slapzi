# SLAPZI! — lettore di indizi

Web app progressiva (PWA) creata da **Flavio Naretti** partendo dal suo progetto Scratch **SLAPZI.sb3**.

L'app **non sostituisce il gioco fisico**: legge e visualizza gli indizi ad alta voce, così nessun partecipante deve restare fuori dal gioco per fare da lettore.

Per giocare serve acquistare le carte originali [SLAPZI di CreativaMente](https://www.creativamente.eu/prodotto/slapzi/).

## Funzioni
- 62 indizi trascritti dal progetto Scratch originale, con estrazione casuale senza ripetizioni nella stessa partita; sono mantenuti anche i duplicati presenti nel mazzo originale.
- Lettura ad alta voce in italiano, selezione timbro femminile/maschile quando le voci del dispositivo lo permettono, pulsante per riascoltare.
- Conteggio indizi rimasti / usciti, annullamento dell'ultima estrazione, nuova partita con conferma.
- Modalità giorno/notte, proiezione e schermo intero, effetti sonori opzionali.
- Salvataggio partita sul dispositivo e funzionamento offline **dopo la prima visita** (la disponibilità della sintesi vocale offline dipende dal sistema operativo).
- Layout responsive per computer, LIM, iPad e smartphone.

## Uso su GitHub Pages
In **Settings → Pages**, scegli **Deploy from a branch**, seleziona **main / (root)** e salva. L'indirizzo sarà:
https://flavionaretti-commits.github.io/slapzi/

La PWA si installa dal menu del browser (ad esempio *Aggiungi alla schermata Home* su iPhone/iPad).

## Comandi
- **Pesca / Prossimo indizio**: estrae e legge un nuovo indizio.
- **Rileggi** (tocco della carta): ripete l'indizio attuale.
- **Annulla**: riporta nel mazzo l'ultima estrazione.
- **Ricomincia**: ripristina l'intero mazzo.
- **Spazio**: pesca; **R**: rilegge (quando il focus non è su un pulsante).

I punti non vengono registrati dall'app: con la variante dell'autore, ciascun giocatore conserva fisicamente le carte conquistate per contarli.
